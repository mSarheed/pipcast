# Changelog

What changed in each Pipcast release, newest first. Pipcast shows this file in What's New, and
the release workflow publishes each version's section as that release's notes.

## 0.1.0

The first release of Pipcast: a fast, native launcher that lives in your menu bar.

### New

- **Launcher** — open apps, System Settings panes and commands with fuzzy search, and bind any of
  them to a global hotkey.
- **Clipboard history** — search everything you copied, text, images and files alike, pin what you
  reuse, and paste it straight into the app you came from.
- **Raycast extensions** — install extensions from the Raycast store and run them natively.
- **Calculator, notes and snippets** — math and unit conversion as you type, a floating Markdown
  note, and snippets that expand from a keyword.
- **Window management** — move and resize windows from the keyboard, save layouts, and switch
  between rooms of apps.
- **AI** — ask Quick AI from the launcher, keep longer chats, and fix, rewrite, translate or
  summarize selected text.
- **And more** — file search, menu bar search, your calendar's next meeting, dictation and an emoji
  picker.
